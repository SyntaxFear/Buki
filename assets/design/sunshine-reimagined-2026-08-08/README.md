# Buki Sunshine reimagining

Twelve full-screen visual concepts derived from the selected Sunshine Studio direction. This is a visual-only round; no application or theme source was changed.

Each concept reimagines all of the following:

- first-screen composition
- `Buki` wordmark treatment
- brand line or trail
- flower, bloom, or terminal brand mark
- primary and supporting colors
- sketchpad shell, binding, tabs, and capture control

## Selection format

Choose complete directions or combine parts, for example:

> Use screen 10, wordmark 01, line and bloom 05, and palette 04.
